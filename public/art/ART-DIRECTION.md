# Catacomb Cats artwork

Direction: underground expedition guild, navy slate stone, worn timber, muted ochre firelight, moss and violet. Strong silhouettes distinguish five cat roles. Square, inset game controls; local pixel fonts; no remote asset requests.

Assets were generated with the built-in image_gen tool, then inspected and integrated. They are generated pixel-style raster artwork, not claimed to be manually authored sprites. The character atlas uses five columns and two rows with transparent square cells. CSS uses nearest-neighbor rendering. Monster variants currently share some base sprites.

## Final prompt set

burrow.png: Production game background for Catacomb Cats. Authentic low resolution pixel art, wide side-view underground medieval cat adventurer guild refuge. Fire pit, cooking pot, rug, bedrolls, stone arches, hanging herbs, amber lamps, crates, maps, dark descending catacomb arch and cat relief. No characters, text or UI. Navy slate shadows, muted ochre light; crisp pixel clusters, no gradients or smoothing.

characters.png (final edit, reference the initial character atlas): Preserve exact character designs, colors, equipment, pixel art style and order. Re-layout ONLY to a wide landscape atlas, five columns by two rows with square cells. Each character fully contained, centered in its square cell, consistent baseline. Top row: orange knight, lilac witch, cream green rogue, calico healer, charcoal brawler. Bottom row: rat, slime, skeleton, bat, crowned king. Transparent background. No text or dividers. Full bodies, not cropped.

crypt.png (style reference burrow.png): Abandoned underground royal crypt battle arena, no characters, UI or text. Same chunky pixel grid, navy slate, muted violet and warm amber palette. Sealed carved stone door with skull cat relief, pillars, torn plum banners, torch braziers. Broad empty tiled floor with cracks and bones only at edges. Side-on RPG stage, not isometric. Hard clusters, no blur or smooth glows.

Fonts: locally bundled Press Start 2P and VT323 via @fontsource; license files included in the installed font packages.
