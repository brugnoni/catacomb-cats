# Rank cap per Expedition instead of reduced repeat loot

Repeating the first Expedition could max every upgrade (about 20 Runs) and leave later Expeditions with no progression. We cap training, Hearth and mastery ranks by the highest unlocked Expedition (4/6/8 and 4/7/10), keep rewards rising per Expedition (x1, x1.5, x2) and never penalise repeating a Run. Unspent gold and XP stay banked.

## Considered Options

- Reduced loot when Power exceeds the Expedition's recommendation: rejected because it adds a rule the player must learn and still lets the first Expedition max everything slowly.
- A fixed Ascension floor per Expedition: rejected because it overshoots the tier cap of 14 at full Power; each Expedition instead has harder base enemies and a Recommended Power.
